ข้อ 2 — ความจำเป็นของเว็บไซต์/AI สำหรับธุรกิจ

20%
🎯 สิ่งที่วัด: เว็บ/AI ที่จะพัฒนา จะแก้ปัญหาธุรกิจอะไรได้จริงมั้ย — ถ้าไม่จำเป็นจริง = เสียงบประมาณ DIP
❓ คำถามหลัก: "เว็บไซต์/AI ที่อยากได้ จะเอาไปแก้ปัญหาอะไรของธุรกิจตอนนี้?"
💬 คำถามตาม: "ตอนนี้ติดอะไร? ถ้าไม่ได้เว็บนี้ ธุรกิจจะเสียโอกาสยังไง?"
คะแนนคำตอบลักษณะนี้ตัวอย่าง
5ระบุปัญหาธุรกิจชัด + อธิบายได้ว่าเว็บ/AI จะแก้ยังไงเป็นขั้นตอน + มีตัวเลขรองรับ"ลูกค้าโทรถามราคา 50 สาย/วัน — เว็บจะช่วยลดงาน admin 70% + AI ตอบ FAQ ได้"
4ระบุปัญหาชัด + แนวคิดแก้สมเหตุสมผล แต่ไม่มีตัวเลขรองรับ"ลูกค้าหาเราในเน็ตไม่เจอ ตอนนี้พึ่งแต่ปากต่อปาก"
3รู้ว่าต้องมีเว็บ แต่บอกได้แค่กว้างๆ"อยากได้ลูกค้าเพิ่ม", "อยากดูเป็นมืออาชีพ"
2ตอบไม่ตรง / ลังเล"ก็... อยากได้เหมือนคนอื่น"
1ไม่รู้ว่าจะเอาเว็บไปทำอะไร"ยังไม่แน่ใจครับ"
🚩 Red flags: "อยากได้เพราะฟรี", "เพื่อนแนะนำ", "มีไว้เฉยๆ", "ใครๆ ก็มี"

ข้อ 3 — สินค้า/บริการชัดเจน แข่งขันได้

15%
🎯 สิ่งที่วัด: ธุรกิจมีตัวสินค้า + target ลูกค้า + จุดต่างชัดมั้ย — ถ้าสินค้ายังเบลอ ทำเว็บไม่ช่วย
❓ คำถามหลัก: "เล่าสินค้า/บริการที่ขายตอนนี้ ลูกค้าหลักคือใคร ต่างจากคู่แข่งยังไง?"
💬 คำถามตาม: "ทำไมลูกค้าถึงเลือกซื้อจากคุณ ไม่ซื้อจากคู่แข่ง?"
คะแนนคำตอบลักษณะนี้ตัวอย่าง
5เล่าได้ครบ — product + target + USP + ราคา + positioning ชัดเจน"ทำขนมเค้กกล่อง เน้น office worker กทม. ราคา 89–129 ใช้วัตถุดิบ premium ส่ง 30 นาที"
4สินค้า + target ชัด แต่ USP ยังกว้าง ("ดีกว่า"/"ถูกกว่า")"ขายกาแฟ ลูกค้าเป็นคนทำงาน — เน้นว่ารสชาติดีกว่า"
3บอกสินค้าได้ แต่ target หรือ USP บอกไม่ชัด"ขายเสื้อผ้าหลายแบบ ลูกค้าหลากหลาย"
2สินค้ายังไม่ชัด / ขายหลายอย่างเกินไป / กำลังจะเริ่ม"ขายของหลายอย่าง อะไรขายได้ก็ขาย"
1ไม่มีสินค้าจริง / ยังไม่ได้เริ่ม / ไม่ตอบ"ยังคิดอยู่ครับ"
🚩 Red flags: "ลูกค้าคือทุกคน", "ขายอะไรก็ได้", "ยังไม่ได้เปิดร้าน"

ข้อ 4 — ประสบการณ์ตลาดออนไลน์ที่ผ่านมา

12%
🎯 สิ่งที่วัด: มี baseline การตลาด online ก่อนเข้าโครงการมั้ย — ถ้ามี = วัดผลก่อน/หลังได้ + เป็น Success Case ง่าย
❓ คำถามหลัก: "เคยทำ FB Ads / LINE OA / Shopee / TikTok มั้ย? ผลเป็นยังไง?"
💬 คำถามตาม: "เคยใช้งบเท่าไหร่/เดือน? ได้ลูกค้ามาจากที่ไหนบ้าง?"
คะแนนคำตอบลักษณะนี้ตัวอย่าง
5ทำหลายช่องทาง + มีตัวเลขผล (CPL, ROAS, conversion) + วิเคราะห์ได้"FB Ads 5,000/เดือน ได้ลูกค้า 30 คน CPL 167 บาท — TikTok ยังไม่ค่อย work"
4ทำต่อเนื่อง + บอกผลคร่าวๆ + เข้าใจ logic"ลง FB กับ Line ขายได้พอควร น่าจะเดือนละ 20–30 ออเดอร์"
3เคยทำเล็กน้อย / ไม่มีระบบ แต่บอกได้ว่าผลออกมาทำไม"ทำเองบ้าง ผลไม่ดีเพราะไม่ได้ตามทุกวัน"
2เคยลอง แต่ไม่เข้าใจผลที่ออกมา"เสียเงิน FB Ads ไปเยอะแต่ไม่รู้ว่าไป"
1ไม่เคยทำเลย / ไม่รู้จัก"ไม่เคยลงโฆษณาเลย"
🚩 Red flags: "เคยเสียเงินไปเยอะ ไม่รู้ผล", "ลูกหลานทำให้ ผมไม่รู้รายละเอียด"

ข้อ 5 — ความตั้งใจในการเข้าร่วม

10%
🎯 สิ่งที่วัด: จะทุ่มเวลาจริงมั้ย — ข้อ 1 เช็คความเข้าใจ "เข้าได้" แต่ข้อนี้เช็ค ทัศนคติ + แผน
❓ คำถามหลัก: "30 ชั่วโมง 5 ครั้ง คือเรื่องใหญ่ — คุณเตรียมเวลายังไง? ใครจะมาแทนถ้าติดธุระ?"
คะแนนคำตอบลักษณะนี้ตัวอย่าง
5เตรียมตัวมาก่อน + บอกได้ว่าจะจัดเวลายังไง + มีแผนสำรอง + กระตือรือร้นชัด"เคลียร์ตารางแล้ว ปกติเข้างาน 9 โมง แต่ช่วงโครงการจะมาก่อน 8 โมง — มีน้องช่วยแทนช่วงเย็น"
4เข้าใจว่าต้องทุ่ม + ตอบดี แต่ไม่มีแผนสำรอง"ตั้งใจมาเองทุกครั้งครับ"
3รับว่าเข้าได้ แต่ไม่บอกแผนชัด"ไม่มีปัญหา ผมว่าจะมาได้"
2ดูลังเล / "ลองดู" / "น่าจะ""ก็... น่าจะ ลองดูครับ"
1บอกแล้วว่าน่าจะติดธุระ / ขอเลื่อนตั้งแต่สัมภาษณ์"ผมไม่ค่อยว่าง ส่งพนักงานไปได้มั้ย"
🚩 Red flags: "ส่งพนักงาน/ลูกชายไปแทน" (ผู้บริหารไม่เข้าเอง — ผิดเงื่อนไข)

ข้อ 6 — ความพร้อมของช่องทางเดิม

8%
🎯 สิ่งที่วัด: มี asset พร้อมใช้ทันทีมั้ย (FB Page, LINE OA, รูปสินค้า, content) — ถ้ามี = พัฒนาเร็ว
❓ คำถามหลัก: "ตอนนี้มี FB Page / LINE OA / รูปสินค้า / content อะไรพร้อมใช้บ้าง?"
คะแนนคำตอบลักษณะนี้
5มีครบ — FB Page + LINE OA + รูปสินค้าคุณภาพดี + คอนเทนต์ต่อเนื่อง
4มี FB + LINE OA + รูปสินค้าพอใช้ + คอนเทนต์มีบ้าง
3มี FB หรือ LINE OA อย่างใดอย่างหนึ่ง + รูปมีบ้าง
2มี FB Page แต่ไม่ active / ไม่มีรูปที่ใช้ได้
1ไม่มีช่องทางออนไลน์เลย หรือมีแต่ไม่ใช้
🚩 Red flags: "ใช้รูปจาก Google มา", "FB ไม่ได้โพสมาปีนึงแล้ว"

ข้อ 7 — ทักษะ digital + พร้อมเรียนรู้ AI

5%
🎯 สิ่งที่วัด: พื้นฐานพอเรียนได้มั้ย — ไม่ต้องเก่ง แต่ต้องไม่กลัวเทคโนโลยี
❓ คำถามหลัก: "ทีมงานใช้เครื่องมือดิจิทัลอะไรอยู่บ้าง? เคยใช้ ChatGPT/AI tool มั้ย?"
คะแนนคำตอบลักษณะนี้
5ใช้ Google Workspace/Notion/Canva + เคยลอง AI tool + แสดงความสนใจชัด
4ใช้ MS Office + Line + เคยลอง AI / อยากเรียนรู้
3ใช้เครื่องมือพื้นฐาน + รู้จัก AI แต่ยังไม่ได้ใช้
2ใช้แต่ Line + ไม่เคยลอง AI
1ไม่ค่อยใช้คอม / กลัวเทคโนโลยี
🚩 Red flags: "ให้ลูกหลานทำให้หมดเลย" (จะไม่ได้เรียนจริง)

🎯Decision Rule (หลังสัมภาษณ์เสร็จทั้ง 30 ราย)
  1. คัดคนที่ไม่ผ่านข้อกำหนดความพร้อม (ข้อ 1 = 0) ออกก่อน → ไม่นำมาจัดอันดับ
  2. เรียงคนที่ผ่านความพร้อม ตามคะแนนรวมจากมากไปน้อย → เลือก top 15
  3. ถ้าคะแนนเสมอ ใช้ลำดับ: ข้อ 2 → ข้อ 3 → ข้อ 4 → ลำดับสมัคร
  4. กระจายสาขา — พยายามให้มีทุกสาขาเป้าหมาย อย่างน้อย 2 ราย/สาขา (ถ้าคะแนนใกล้กัน)
  5. กระจายพื้นที่ — ไม่กระจุกจังหวัดเดียวเกิน 60%
  6. เสนอ DIP เห็นชอบ 6–7 มิ.ย. → ประกาศผล 8 มิ.ย.
